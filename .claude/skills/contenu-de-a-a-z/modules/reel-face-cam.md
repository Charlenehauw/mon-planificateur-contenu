# Reels face cam : inspis, script, montage

## Étape 0 : les inspis (avant tout premier montage)
Demande 3 à 5 vidéos qui lui plaisent (fichiers, captures ou lien d'un dossier INSPIS). Pour chacune, repère :
- type de contenu (face cam, voix off, motion, B-roll, tuto, avant/après) ;
- rythme (durée des plans, vitesse des coupes) ;
- sous-titres (police, taille, couleur, position, animation) ;
- effets, transitions, animations ;
- sons (bruitages, musique, voix) ;
- ce qui accroche dans les 2 premières secondes.
Demande aussi ce qu'elle n'aime pas. Rédige une fiche **MON STYLE DE MONTAGE** et propose de l'ajouter au brief.

## Étape 1 : le script (30 secondes par défaut)
1. ACCROCHE (2 s) : une phrase qui arrête le scroll, en mode conversation.
2. TENSION (5 s) : le problème vécu par la cible.
3. VALEUR (15 s) : 3 points concrets, phrases très courtes.
4. PREUVE (5 s) : une expérience vraie du brief.
5. ACTION (3 s) : « Écris [MOT-CLÉ] en commentaire / en DM ».
Ajoute entre crochets les plans à filmer. Propose 10 accroches alternatives (questions, phrases choc, POV) classées de la plus forte à la moins forte. Option « prompteur » : une phrase par ligne, respirations marquées par « / ».

## Étape 2 : le montage
Si tu peux exécuter du code (Python + ffmpeg / moviepy) et qu'elle t'envoie le rush :
- coupe les pauses **de plus de 0,7 s uniquement** (en douceur, garde le naturel, jamais mot par mot) ;
- sous-titres mot à mot selon la fiche style, mots importants mis en valeur ;
- effets demandés, bruitages discrets synchronisés, CTA final ;
- format 9:16, 1080×1920 ; envoie un aperçu (images clés) avant le rendu final.
Sinon, livre une **feuille de montage** minutée (timecode → coupe / texte / effet / son) à appliquer dans son application.

## Catalogue d'effets à proposer
| Effet | Ce que ça donne |
|---|---|
| Blancs coupés | plus de « euh » ni de silences |
| Sous-titres mot à mot | chaque mot apparaît quand il est dit |
| Zoom punch | petit zoom rapide sur une phrase forte |
| Écran partagé avant/après | rush brut à gauche, montage à droite |
| Pastilles qui pop | étiquettes qui apparaissent avec un « pop » |
| Mot barré | un mot rayé puis remplacé |
| Flou d'arrière-plan | pour faire ressortir un texte |
| Maquette de téléphone / mockup produit | écran ou produit mis en scène |
| Machine à écrire | texte lettre par lettre |
| Compteur | chiffre qui défile jusqu'à sa valeur (chiffre vrai uniquement) |
| Transitions | glissé, fondu, whip pan + whoosh |
| Détourage | la personne devant un fond |
| CTA final | « commente [MOT-CLÉ] » en grand |

## Retours
Applique chaque retour précis (« enlève le zoom à 0:08 », « sous-titres plus gros ») sur ce reel uniquement, puis propose d'en faire une règle du brief.
